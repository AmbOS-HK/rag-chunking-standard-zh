# RAG 知识库切片质量标准与验收清单（中文场景）

面向中文语料场景的 RAG 知识库切片质量标准、验收清单与配套评审材料。厂商中立，不绑定具体平台；上位依据为 ITU-T F.748.52（2025）与 GB/Z《人工智能关键技术 检索增强生成系统测评规范》（征求意见稿）。

> **定位声明**：本标准面向中文语料场景制定。英文或多语言语料的数值基线应另行校准，不应直接套用本标准的中文经验值。

## 证据分级口径

- **A**＝ITU-T F.748.52（现行国际标准）；
- **B**＝GB/Z 征求意见稿（框架与公式，不设数值阈值）；
- **C**＝公开研究/benchmark 与行业经验值（含 ACM TOIS、SIGIR、AAAI 正式发表与 arXiv 预印本，载体差异逐条注明）。

所有数值合格线均为 C 级经验值，须以目标平台自建基线 A/B 复验后方可固化。

## 主要证据来源

- CRUD-RAG（arXiv:2401.17043；ACM TOIS 43(2)，2025；DOI 10.1145/3701228）——中文 RAG 基准，chunk size / overlap 系统扫描
- Legal-DC（arXiv:2603.11772，预印本）——中文法律文书 RAG 基准，条文级结构切分证据
- HOPE（ACM SIGIR 2025；DOI 10.1145/3726302.3729882）——切片质量评估框架（语义独立性）
- arXiv:2601.14123（ECIR 2026 短篇）／arXiv:2604.12047（ICSE-SEIP 2026）——overlap 对照证据
- RGB（arXiv:2309.01431；AAAI 2024）——中英双语 RAG 鲁棒性基准

## 文档再生成

文档由 `scripts/` 下的 docx-js 脚本生成（单一事实源，改文档请改脚本后重新生成）：

```bash
npm install docx
node scripts/create_v31.js docs/RAG切片质量标准与验收清单_V3.1_修订草案.docx
```

生成后校验：

```bash
python tools/validate_docx.py docs/*.docx
```

## 版本纪律

- 标准版本号（V3.x）随文档内容演进；修订记录写入 V3.1"修订说明与对照表"（R 编号）；
- 附录 A 基线条目经验证后由【待验证】改为【已验证 vX.X】，注明评测集版本、平台、模型、日期；
- 评测集冻结后只增不改，修改即升版。

版本载体、文档升版关联关系与升版检查清单详见 [VERSIONING.md](VERSIONING.md)。
